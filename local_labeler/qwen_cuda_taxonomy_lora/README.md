# qwen_cuda_taxonomy_lora

QLoRA-дообучение Qwen3-8B для разметки reasoning-трейсов на **3-классовой** схеме causality
(`0` отсутствует / `1` упомянуто / `2` ключевой аргумент).

> **Это предшественник, а не актуальная серия.** Работа продолжена
> в [`../qwen_cuda_binary_lora/`](../qwen_cuda_binary_lora/), где causality переведена на бинарную
> схему `0/1`. Причина: класс `2` не встретился ни в одном из 19 causality-полей тестового набора —
> метрика де-факто считалась по `{0, 1}`, тогда как модель обучалась предсказывать `2`. Разбор —
> в [`../qwen_cuda_binary_lora/EXPERIMENTS.md`](../qwen_cuda_binary_lora/EXPERIMENTS.md).
>
> Папка сохранена в неизменном виде, чтобы серия оставалась воспроизводимой и служила базой
> для сравнения. Новые эксперименты сюда не добавляются.

Порт MLX-версии [`../qwen_mps_taxonomy_lora/`](../qwen_mps_taxonomy_lora/) на CUDA-стек
(`transformers` + `peft` + `bitsandbytes`): ядро то же — промпты, нормализация, метрики,
переписан только движок обучения и инференса.

## Результаты серии (3 класса)

Основной критерий — `mean_f1_all` (macro-F1, усреднённый по 37 полям) при guardrail
`mean_f1_good ≥ 0.943`.

| Эксп. | Изучаемый фактор | `mean_f1_all` | `mean_f1_collapsed` | `mean_f1_good` |
|---|---|---|---|---|
| E0 | контроль | 0.7585 | 0.5986 | 0.9733 |
| E1 | глубина адаптера: 4→36 слоёв | 0.7963 | 0.6678 | 0.9782 |
| E2 | ранг: 8→4 | 0.7931 | 0.6664 | 0.9781 |
| **E3** | **lr=1e-4 + cosine** | **0.8124** | **0.6852** | 0.9806 |
| E4 | lr=3e-4 | 0.8084 | 0.6834 | 0.9807 |
| E5 | dropout=0.01 | 0.8077 | 0.6820 | **0.9809** |
| — | *baseline (прод-разметчик)* | *0.667* | *0.480* | *0.943* |

Лидер серии — E3 (0.8124). В бинарной серии этот результат превзойдён E7 (0.8204).

```bash
bash select_best_checkpoint.sh E3
```
